# PROMPTS

## AI Usage Philosophy

StackSpend intentionally avoids using LLMs for:

* pricing calculations
* optimization decisions
* financial recommendations

These systems are implemented using deterministic rule-based logic to ensure:

* explainability
* predictable outputs
* financially defensible recommendations

AI is planned only for:

* concise narrative summaries
* user-facing audit explanations

This separation was chosen intentionally to avoid hallucinated financial recommendations.
