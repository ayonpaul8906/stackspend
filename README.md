# StackSpend

StackSpend is an AI subscription audit platform that helps startups and teams identify overspending across tools like ChatGPT, Claude, Cursor, GitHub Copilot, Gemini, and AI APIs.

Users can audit their AI stack, discover unnecessary subscriptions, optimize seat allocation, and estimate monthly + annual savings through a shareable financial audit report.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Supabase
- Resend
